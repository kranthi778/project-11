# Project 11 – Denial-of-Service (DoS) Attacks

## Overview

I practiced Denial-of-Service (DoS) attacks as part of my CEHv13 cybersecurity learning. This project mixed theory with tests in a controlled lab using Kali Linux, Ubuntu, Metasploit Framework, hping3 and Wireshark.

The goal was to learn DoS attack methods see how they affect network services and analyze traffic from a defenders point of view using packet analysis tools.

## Topics Covered

- TCP SYN Flood

- UDP Flood

- ICMP Flood

- TCP SYN Flood using Metasploit Framework

- Slowloris Attack

- Wireshark Traffic Analysis

- Network Resource Exhaustion

- DoS Detection Concepts

- SOC Analyst Perspective on DoS Attacks

## Lab Environment

**Attacker Machine**

- Kali Linux

**Target Machine**

- Ubuntu 26.04 LTS

**Tools Used**

- Metasploit Framework for DoS attacks

- hping3 for generating flood traffic

- Wireshark for packet analysis

- Slowloris for application-layer DoS

- Git for version control

- Linux Terminal for commands

## Skills Demonstrated

- I performed controlled DoS attack simulations.

- I used Metasploit modules for DoS attacks.

- I generated TCP, UDP and ICMP flood traffic with hping3.

- I demonstrated application-layer DoS with Slowloris.

- I. Analyzed packets with Wireshark.

- I understood network behavior during DoS attacks.

- I documented cybersecurity labs professionally.
